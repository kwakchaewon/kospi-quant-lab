# Factor 판단 로직

`merge_data.py`에서 각 종목에 대해 4가지 Factor를 평가합니다.
F1·F2는 자동 계산, F3·F4는 Claude 웹검색으로 보완하는 placeholder입니다.

---

## Factor 1 — 기술 (가격 위치)

v4.0 기준 (2026-04-16)

### 케이스 A: 정배열 눌림

```
현재가 > MA60  AND
현재가 > MA120 AND
현재가 <= MA20 AND
40 <= RSI(14) <= 78
```

- 중장기 정배열 상태에서 단기 이평선 아래로 눌린 구간
- 추세는 살아있되 단기 과매도 구간 진입을 노림

### 케이스 B: 정배열 돌파

```
현재가 > MA20 > MA60 AND
현재가 >= 최근20일고가 × 0.87 AND
45 <= RSI(14) <= 78
```

- 단·중기 이평선이 완전 정배열인 상태에서 고점 근처 돌파 시도
- RSI 상단 78 미만 조건으로 과열 구간 제외

### 결과

- `✅ 충족` + 케이스명 (케이스A 또는 케이스B)
- `❌ 미충족` + `케이스없음`

## Factor 2 — 수급 (기관/외국인)

v3.0 기준 (2026-04-16)

### 탈락 조건 (먼저 체크, 하나라도 해당 시 즉시 ❌)

| 탈락 | 조건 |
|---|---|
| 탈락1 | 외국인 최근 **2일 연속** 순매도 |
| 탈락2 | 기관 최근 **5일 중 순매도 3일 이상** |
| 탈락3 | 최근 **5일 기관+외국인 동시 순매수 0일** |

### 충족 조건 (탈락 없음 AND 3개 모두 충족)

| 조건 | 기준 |
|---|---|
| 조건1 | 기관 **20일 누적 순매수 > 0** AND **20일 중 순매수 10일 이상** |
| 조건2 | 외국인 **최근 5일 중 순매수 3일 이상** |
| 조건3 | 최근 **5일 기관+외국인 동시 순매수 2일 이상** |

### 데이터 소스

`naver_investor_crawl.py`가 수집한 최근 20거래일 투자자 매매동향 사용.
데이터가 없으면 자동으로 `❌ 미충족` 처리.

## Factor 3 — 실적 (placeholder)

`merge_data.py`에서 `None`으로 출력되며, `stock_data_full.json`을 Claude에 업로드한 후 웹검색으로 채웁니다.

참고 데이터 (yfinance로 수집):

- `영업이익_최근연도` / `영업이익_전년도`: 연간 영업이익 YoY 비교
- `next_earnings_date`: 다음 실적 발표일

## 집계 분류

`merge_data.py`는 F1·F2 결과를 기준으로 종목을 4개 버킷으로 분류합니다.

| 분류 | 조건 |
|---|---|
| F1+F2 모두 충족 | F1 ✅ AND F2 ✅ |
| F1만 충족 | F1 ✅ AND F2 ❌ |
| F2만 충족 | F1 ❌ AND F2 ✅ |
| 둘 다 미충족 | F1 ❌ AND F2 ❌ |

둘 다 미충족 종목은 `투자자_매매동향` 배열이 제거되어 최종 JSON 용량을 절감합니다.
