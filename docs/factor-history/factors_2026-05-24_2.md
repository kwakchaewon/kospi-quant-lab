# Factor 판단 로직

`merge_data.py`에서 각 종목에 대해 4가지 Factor를 평가합니다.
F1·F2는 자동 계산, F3·F4는 Claude 웹검색 분석 프롬프트로 별도 평가합니다.

---

## Factor 1 — 기술 (가격 위치)

v4.0 기준 (2026-04-16)

### 케이스 A: 정배열 눌림

```
현재가 > MA60  AND
현재가 > MA120 AND
현재가 <= MA20 AND
40 <= RSI(14) <= 78
```

- 중장기 정배열 상태에서 단기 이평선 아래로 눌린 구간
- 추세는 살아있되 단기 과매도 구간 진입을 노림

### 케이스 B: 정배열 돌파

```
현재가 > MA20 > MA60 AND
현재가 >= 최근20일고가 × 0.87 AND
45 <= RSI(14) <= 78
```

- 단·중기 이평선이 완전 정배열인 상태에서 고점 근처 돌파 시도
- RSI 상단 78 미만 조건으로 과열 구간 제외

### 결과

- `✅ 충족` + 케이스명 (케이스A 또는 케이스B)
- `❌ 미충족` + `케이스없음`

## Factor 2 — 수급 (기관/외국인)

v3.0 기준 (2026-04-16)

### 탈락 조건 (먼저 체크, 하나라도 해당 시 즉시 ❌)

| 탈락 | 조건 |
|---|---|
| 탈락1 | 외국인 최근 **2일 연속** 순매도 |
| 탈락2 | 기관 최근 **5일 중 순매도 3일 이상** |
| 탈락3 | 최근 **5일 기관+외국인 동시 순매수 0일** |

### 충족 조건 (탈락 없음 AND 3개 모두 충족)

| 조건 | 기준 |
|---|---|
| 조건1 | 기관 **20일 누적 순매수 > 0** AND **20일 중 순매수 10일 이상** |
| 조건2 | 외국인 **최근 5일 중 순매수 3일 이상** |
| 조건3 | 최근 **5일 기관+외국인 동시 순매수 2일 이상** |

### 데이터 소스

`naver_investor_crawl.py`가 수집한 최근 20거래일 투자자 매매동향 사용.
데이터가 없으면 자동으로 `❌ 미충족` 처리.

## Factor 3 — 실적

`stock_data_full.json`을 Claude에 업로드한 후 웹검색 프롬프트로 평가합니다.
**분석 대상:** F1+F2 모두충족 · F1만충족 · F2만충족 종목 (둘다_미충족 제외)

### 웹 검색 (종목당 최대 3회)

1. `"{종목명} 분기 영업이익 컨센서스 어닝서프라이즈"`
2. `"{종목명} 영업이익 분기 YoY 전년동기"`
3. `"{종목명} 목표주가 상향 하향 2026"`

### 판정 기준 (3개 중 2개 이상 충족 시 ✅)

| 번호 | 항목 | 충족 조건 |
|---|---|---|
| ① | 어닝서프라이즈 | (실제 − 컨센서스) / 컨센서스 × 100 > **+5%** |
| ② | 영업이익 분기 YoY | 전년 동기 대비 **증가** |
| ③ | 목표주가 | 최근 3개월 상향 리포트 **≥ 2건** |

- 충족 **≥ 2** → `✅ 충족`
- 충족 **≤ 1** → `❌ 미충족`
- 데이터 부족 **≥ 2** → `❓ 데이터부족`

### 특수사유 체크 (해당 시 ⚠️)

공개매수 · 주식병합 · 액면분할 · 관리종목 · 거래정지 · 상장폐지우려 · 대규모감자 · 회계감사 비적정 · 공정위 조사

### 출력 필드

```
종목명, 종목코드, F3_판정, F3_근거(①②③), 특수사유, F3_메모(1줄)
F3_판정 ❌ 또는 특수사유 ⚠️ → F4_대상=false
```

### 참고 데이터 (자동 수집)

- `earnings_surprise_latest`: 최근 분기 어닝서프라이즈 (%)
- `영업이익_최근연도` / `영업이익_전년도`: 연간 영업이익 YoY
- `next_earnings_date`: 다음 실적 발표일

## Factor 4 — 밸류

**분석 대상:** F3 판정 ✅ + 특수사유 없음 (`F4_대상=true`) 종목만

### 웹 검색 (종목당 최대 2회)

1. `"{종목명} Forward PER 12개월 선행"`
2. `"{종목명} 업종 평균 PER 동종업계"`

### 판정 기준

```
ratio = Fwd PER ÷ 업종평균 PER
```

| ratio | 판정 |
|---|---|
| < 1.0 | `✅ 충족` |
| 1.0 ~ 1.3 | `유지` |
| > 1.3 | `⚠️ 고평가주의` |
| > 2.0 | `❌ 미충족` |
| 데이터 부족 | `❓ 데이터부족` |

### 출력 필드

```
종목명, 종목코드, F4_판정, Fwd_PER, 업종평균_PER, ratio, F4_메모(1줄)
```

### 참고 데이터 (자동 수집)

- `PER` / `FPER` (네이버 금융)
- `forwardPE` / `analyst_price_targets` (yfinance)

## 집계 분류 및 분석 흐름

### F1·F2 자동 분류 (merge_data.py)

| 분류 | 조건 |
|---|---|
| F1+F2 모두 충족 | F1 ✅ AND F2 ✅ |
| F1만 충족 | F1 ✅ AND F2 ❌ |
| F2만 충족 | F1 ❌ AND F2 ✅ |
| 둘 다 미충족 | F1 ❌ AND F2 ❌ |

F3·F4 웹검색 분석은 둘다_미충족 종목을 제외한 나머지 3개 버킷에 대해서만 수행합니다.

### F3·F4 분석 흐름 (Claude 웹검색)

```
F1·F2 분류
  └─ 모두충족 / F1만 / F2만  →  F3 실적 분석
                                   ├─ F3 ✅ + 특수사유 없음  →  F4 밸류 분석
                                   └─ F3 ❌ / ⚠️             →  F4_대상=false (종료)
  └─ 둘다 미충족               →  F3·F4 분석 제외
```
